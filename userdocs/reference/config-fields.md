# Config fields: profiles, devices, calibration, chassis

Generated by a script from the pydantic models (`src/qcss/config/profile.py`, `device.py`) for type/default/required, and from the Explorer explanations YAML for the descriptions. All models are `extra="forbid"` where declared so; times are in ticks of `clock.tick_hz` unless a name says otherwise. Fields marked `unverified` in provenance (`verified: false`) are estimates, not vendor-checked.

## Shipped files

- Profiles (`src/qcss/config/profiles/`): `qblox_cluster_5q`, `qick_zcu216_4q`, `qick_zcu216_5q`, `test_ideal_1q`, `zi_shfqc_5q` (.yaml). Select with `qcss serve --profile NAME|PATH`.
- Devices (`src/qcss/config/devices/`): `test_ideal_1q`, `transmon_5q` (.yaml). Select with `--device NAME|PATH`.
- Loader: `load_profile`, `load_device` (`src/qcss/config/loader.py`); `get_unverified_fields(profile)` lists `verified: false` blocks.
